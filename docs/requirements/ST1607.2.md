# MISB ST 1607.2 requirement trace

The checksum-pinned MISB ST 1607.2 publication dated 11 June 2025 contains
eight active requirements and one retired requirement. The machine-readable
inventory records that exact population and binds it to the acquired source
digest. ST 0601 Items 100 and 101 instantiate the generic Segment and Amend
constructs using ST 0601 child tags and Item 143 as the Metadata Substream ID
(MSID).

The codec reads and writes the nested Local Set values without inventing an
outer Universal Key, length, or checksum; preserves original TLVs; types known
ST 0601 child values; retains extension TLVs; and bounds recursion. The receiver
state retains first-generation root metadata separately, applies Segment union
and override, and represents Amend ZLIs as expiring deletion overlays.

The generic tree evaluator and Report-on-Change lineage tracker are implemented
by `MetadataTreeState`. It also enforces exactly one MSID per branch, stable
parent lineage, stable branch kind, bounded branch/field counts, and inclusive
30-second retention. These details are imposed by the instantiating ST 0601
profile rather than by an additional numbered ST 1607.2 requirement.

`validate_st1602_composite` applies cross-packet composite-image policy without
mistaking an inherited parent Item 94 for a child sensor identifier, while
`MetadataTreeSnapshot.effective_composite_timestamp` resolves an explicit
Composite Imaging timestamp or its immediate parent's effective timestamp.

## External applicability boundaries

The stream alone cannot establish whether a child's object country is unique;
the producer or caller supplies that applicability fact by including the child
Security Local Set, after which its exact shape is enforced. Requirements
ST 1607-05 and ST 1607-06 defer the required population to the selected MISP;
the bundled validator proves the airborne MISMMS profile, while a different
deployment profile must supply its own completeness policy.

## Retired requirement

ST 1607-03 is retained only in the inventory as retired. Its former fixed list
of root security items is not presented as a current conformance rule; the
active ST 1607-01 and ST 1607-02 inheritance rules and the source-bound
ST 0102.12 validator govern current security metadata.
