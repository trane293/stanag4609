# MISB ST 1607.2 requirement trace

The official ST 1607.2 publication dated 11 June 2025 defines generic Segment
and Amend Local Sets. ST 0601 Items 100 and 101 instantiate those constructs
using ST 0601 child tags and Item 143 as the Metadata Substream ID (MSID).

This implementation parses nested sets without a Universal Key, outer length,
or checksum; preserves their original TLVs; types known ST 0601 child values;
retains unknown extension TLVs; and bounds recursive decoding. Amend ZLIs are
represented explicitly as deletion operations rather than ordinary unknowns.

| Requirement | Implementation/test | State |
|---|---|---|

| ST 0601.19-43/-44, parent lineage | full MSID paths, recursive observation, and identity stability validation | Verified |

| ST 1602-04 / ST 1602.1-10 composite child policy | `validate_st1602_composite` over retained Segment branches | Verified for sibling Z-order scope and direct child MIIS identifiers |

The generic tree evaluator and report-on-change lineage tracker are implemented
by `MetadataTreeState`; `validate_st1607_security` enforces child-country and
root-inheritance policy. `validate_st1607_mismms` applies the airborne MISMMS
profile to the hierarchy level required by each construct.
`validate_st1602_composite` applies cross-packet composite-image policy without
mistaking an inherited parent Item 94 for a child sensor identifier.
`MetadataTreeSnapshot.effective_composite_timestamp` resolves an explicit
Composite Imaging timestamp or the effective timestamp of its immediate parent.
