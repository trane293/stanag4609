# ITU-T H.222.0 (10/2014) requirement trace

The MPEG-2 Systems transport baseline is ITU-T H.222.0 (10/2014), equivalent
to ISO/IEC 13818-1:2015. This trace records only implemented and directly
tested slices; it is not a full systems-layer conformance claim.

| Standard basis | Implementation/test | State |
|---|---|---|

| Table 2-6, adaptation-field flags and optional-field syntax | `AdaptationField`, `AdaptationFieldExtension`, canonical encoders, packet parser, verifier, and exact-byte round-trip tests | PCR/OPCR, stream priority, signed splice countdown, bounded private data, legal-time-window, positive piecewise rate, seamless-splice timestamp, marker/reserved bits, and stuffing verified for reading and writing |
| Equations 2-1 through 2-3, PCR base × 300 + extension at 27 MHz | exact clock model and round-trip tests | Verified |
| Clause 2.4.3.5, PCR carried on the PMT-declared PCR PID | program-aware clock events and public FMV integration tests | Verified |
| Clause 2.4.3.5 / ST 1402.2 §7.2, PCR interval | `PCRCadenceValidator` program, rollover, discontinuity, and exact-boundary tests | Observed spacing verified; accuracy/jitter pending |
