RFC 2781 text accepts an explicit big- or little-endian byte-order mark. In
its absence the decoder uses network-order UTF-16BE; the encoder emits UTF-16BE
without a byte-order mark.

The codec validates vocabulary shape—alphabetic versus numeric, expected code
width, separators, and mixed-code consistency—but intentionally does not ship a
stale geopolitical-code database. Applications remain responsible for choosing
the authoritative dated GENC, ISO 3166, STANAG 1059, or legacy FIPS code list
identified by Tags 23 and 24.

`MISMMSecurityContext` carries deployment policy separately from wire decoding.
It can require an exact classification, classifying country, SCI/SHI string,
and caveats string, plus membership of specific Releasing and Object Country
codes. This makes policy mismatch machine-reportable without embedding a
mission-specific marking decision in the library.
