# MISB ST 0102.12 requirement trace

This trace is bound to the acquired 22 June 2017 publication and accounts for
all 38 active requirements and all 28 requirements that edition explicitly
deprecated. The implementation covers both the Security Metadata Universal Set
and the Security Metadata Local Set carried by ST 0601 Item 48.

## Software-verifiable requirements

| Requirement | Implementation and evidence | State |
|---|---|---|
| ST 0102.10-02 | Universal and Local Set codecs use the strict ST 0107/SMPTE ST 336 key, BER Length, and BER-OID primitives | Verified for both current set forms |
| ST 0102.10-03 | Security Classification is required and maps the five defined Universal text values to the Local `uint8` domain | Verified |

| ST 0102.12-65 | `SecurityUniversalSet`, `encode_security_universal_set`, and `decode_security_universal_set` implement the registered outer key and all Table 1 constituent ULs with bounded KLV parsing and lossless unknown-item retention | Verified |
| ST 0102.12-66 | `SecurityLocalSet`, `encode_security_local_set`, and `decode_security_local_set` implement the registered Local Set key, Table 2 tags, canonical writing, and lossless unknown-item retention | Verified |

The two representations expose equivalent typed values. Security
Classification, Country Coding Method, and Object Country Coding Method are
converted between the exact uppercase Universal Set symbols and their compact
Local Set integers. RFC 2781 object-country text accepts an explicit big- or
little-endian byte-order mark; absent a marker, decoding uses UTF-16BE and
encoding emits UTF-16BE.

## Producer and security-authority obligations

| Requirement | Obligation and library boundary | State |
|---|---|---|
| ST 0102.10-26 | The Object Country Code includes the geographic region beneath frame center | Producer geospatial truth; vocabulary shape is validated |
| ST 0102.10-27 | Classification Comments contain only non-essential security information | Content-policy obligation; printable wire text is validated |
| ST 0102.10-55 | Imagery receives its proper classification, handling, caveats, and release instructions | Security authority selects policy; caller contexts make exact mismatches machine-reportable |
| ST 0102.10-59, ST 0102.10-60 | U.S. producers use GENC/ISO guidance and legacy systems migrate on upgrade | Deployment/procurement obligation; current and legacy wire vocabularies remain interoperable |
| ST 0102.11-63, ST 0102.11-64 | Releasing countries follow mission security guidance and, for U.S. systems, DoD Manual 5200.01 Volume 2 | Security-authority obligation; caller policy can require exact country membership |

The codec intentionally does not bundle a geopolitical database that would
become stale. Tags 23 and 24 retain the selected code-list dates, while callers
choose the authoritative GENC, ISO 3166, STANAG 1059, or legacy FIPS list.
