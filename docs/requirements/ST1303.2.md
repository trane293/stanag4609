# MISB ST 1303.2 requirement trace

This trace covers the official 25 June 2020 Multi-Dimensional Array Pack
publication. An MDAP is a context-dependent KLV truncation pack: the invoking
standard supplies the meaning and, for Natural and RLE arrays, the element
type. The codec therefore requires an explicit `MDAPElementType` rather than
guessing a numeric interpretation from bytes.

Decoded RLE arrays remain compact. `element_at()` resolves a cell by scanning
patches in reverse order, preserving the standard's last-patch-wins behavior;
`materialize()` expands only under an explicit element limit. Decoding also
bounds pack length, dimensions, total logical elements, element width, and RLE
patch count before allocating corresponding structures.

IEEE bounds used by IMAP are quantized to their actual 32-bit or 64-bit wire
representation before element mapping. This ensures a receiver reconstructs
the same mapping and makes decode-then-encode stable at parameter boundaries.
