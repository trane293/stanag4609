## Normative algorithm and tables

The active numbered requirements govern negative zero and notation. The
edition's normative algorithm remains essential implementation evidence even
though Section 9 deprecated its earlier numbered statements:

| Source area | Implementation evidence | Test evidence | State |
|---|---|---|---|
| §7.1.1 / equations 22-23, IMAPA length | `imap.imapa_length` uses exact rational log-two boundaries | all Appendix A IMAPA length examples and Test 1 | Verified |
| §7.1.2, IMAPB constants | `IMAPB` exposes exact rational forward/reverse scales and zero offset | Appendix A Examples 3-4 and Tests 2-3 | Verified |
| §7.2.1, forward mapping | range checks, exact power-of-two scaling, zero offset, and truncation in `IMAPB.encode` | every normal and overflow vector in Appendix A Tests 1-3 | Verified |
| §7.2.2, reverse mapping | `IMAPB.decode` validates length and reverse maps exact code words | every normal vector in Appendix A Tests 1-3 | Verified |
| Tables 1-3, IEEE/MISB/user/reserved values | `IMAPSpecialKind` and lossless `IMAPSpecialValue`; positive and negative quiet NaNs; infinity, signaling-NaN, user, MISB, and reserved classification | canonical patterns, unknown-pattern retention, and byte-exact re-encode tests | Verified |
| §7.2.3.1 parent-unspecified overflow behavior | `IMAPOverflowPolicy.CLAMP` resolves below/above signals to the range bounds; lossless preservation remains the low-level default for parent-specific handling | lower/upper bound resolution tests | Verified |
| §7.4 alternate KLV length | each `IMAPB` instance derives constants from its actual byte length and rejects mismatched values | multi-length and length-validation tests | Verified |

The decoder deliberately preserves special values by default. This is required
for a general-purpose KLV library because invoking standards can assign
item-specific meanings. Callers whose parent document provides no alternate
overflow behavior can select `IMAPOverflowPolicy.CLAMP` to apply the ST 1201
minimum/maximum default without losing the low-level wire signal elsewhere.

`ST 1201.1-04`, `ST 1201.1-05`, `ST 1201.1-06`, `ST 1201.1-07`,

deprecated. They remain represented by the normative algorithm tests above,
but are not counted as active conformance requirements.
