# MISB ST 1201.5 requirement trace

This trace uses the official 24 June 2021 publication. The implementation uses
exact rational arithmetic for all one-time constants and code-word boundaries,
then returns ordinary Python floats for numeric decoded values.

| Requirement/area | Implementation/test | State |
|---|---|---|
| §7.1.1 / equations 22–23, IMAPA length selection | `imap.imapa_length`, official examples | Verified |
| §7.1.2, IMAPB scale factors and zero offset | `imap.IMAPB`, Tests 2–3 | Verified |
| §7.2.1, forward mapping and truncation | `IMAPB.encode`, official vectors | Verified |
| §7.2.2, reverse mapping | `IMAPB.decode`, official vectors | Verified |
| §7.2.3, IEEE and MISB special values | lossless `IMAPSpecialValue` | Verified subset |
| ST 1201.1-12, negative zero mapping | `test_imap.py` | Verified |
| Reserved and user-defined bit preservation | lossless raw code words | Tested |

NaN payload creation is intentionally conservative: encoding Python `nan`
produces the canonical positive quiet-NaN pattern, while explicitly decoded
NaN identifiers, user-defined values, and reserved values retain their exact
wire bytes for re-encoding.
