# MISB ST 1601.2 requirement trace

Normative source: `ST1601.2.pdf`, dated 2 March 2023. Registry data types were
cross-checked against the official ST 0807.27 workbook. Both local files are
checksum-pinned and not distributed.

The heterogeneous uncertainty wrapper is intentional: ST 1601 assigns
different IMAPB bounds to different rows while ST 1303 carries those values in
a Natural MDAP with a uniform element width.

Section 1 says to include the Geo-Registration LS only in an existing Local Set
that contains sensor-model items. It expresses Amend usage as the intent of the
standard, not as an exclusive-carriage requirement. The implementation
therefore supports Item 98 in the ST 0601 root and in Segment/Amend branches,
without inventing a prohibition absent from the normative text.
