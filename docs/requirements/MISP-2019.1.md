# MISP-2019.1 applicability trace

STANAG 4609 Edition 5 adopts MISP-2019.1 as its technical standard. This table
maps the requirements applicable to this library's Class 1/Class 2 MPEG-2
Transport Stream profile. Producer hardware truth, native SDI, MXF, NITF,
JPEG2000, Class 3 conversion, JPIP, and service-control protocols are not
silently treated as Python byte-library requirements.

| MISP requirements | Library evidence | Assessment |
| --- | --- | --- |
| 2015.1-01/-02, source aspect ratio and progressive scan | `MISPImageContext`, H.262/AVC/HEVC sequence-property parsers, and verifier | Producer-supplied source aspect ratio and source/conversion scan history are validated explicitly; encoded scan signalling is checked across every observed sequence property set for all three codecs |
| 2018.3-116, every frame has Absolute Time; 2018.1-97/-98, metadata time system and single coordinate | ST 0604 timestamp-to-access-unit parser/verifier; ST 0601 Item 2 plus ST 0603 conversion/state | Per-access-unit timestamp presence, duplicates, orphan messages, and metadata time representation verified for the selected H.262/AVC/HEVC profile; producer clock truth remains external |
| 2015.1-07 through -10, KLV/ST 0107/ST 1201/ST 1303 | KLV, IMAP, local-set, MDAP implementations and dedicated traces | Implemented applicable wire structures |
| 2015.1-11, approved containers | core accepts MPEG-2 TS; reference player prepares browser MP4 as an output derivative | Verified only for the selected MPEG-2 TS library profile |
| 2015.1-17 through -22, uncompressed Class 0 sampling formats | — | Not applicable to this Class 1/Class 2 compressed transport profile; encoded dimensions, rate, chroma, and bit depth remain inspectable where codec headers signal them |
| §3.6.2, Class 1 Pixel Value Range | H.262/AVC/HEVC sequence-property parsers and verifier | Every observed sequence property set is checked against the maximum of eight bits per band; this is reported separately from codec profile/level because HEVC Main 10 permits both 8-bit and 10-bit coding |

The verifier also enforces **MISP-2015.1-49** directly: if populated ST 0102
Security Metadata is observed through both synchronous and asynchronous KLVA
carriage in one MPEG-2 TS program, `misp.security.multiple_carriage` is an error.
One observed carriage mechanism produces the corresponding evidence-bearing pass.
