# MISB ST 1204.3 requirement trace

This trace covers the binary MIIS Core Identifier grammar used by ST 0601 Item
94, the software-verifiable UUID generation rules, and receiver-visible
insertion cadence. Device identity truth and physical sensor-change timing
remain producer inputs rather than facts a decoder can infer.

| Requirement | Section | Implementation/test | State |
|---|---:|---|---|
| Core Identifier EBNF | 7.1 | `MIISCoreIdentifier` component validation | Verified |
| Current structural version | 7.2 | BER-OID version decode; unsupported versions rejected | Verified |
| Usage Value mapping | 7.3.1 Table 3 | quality bits, inclusion bits, and reserved-bit checks | Verified |
| Binary component ordering | 7.4.1 Table 5 | Sensor, Platform, Window, or Minor UUID order | Verified |
| Binary examples | Appendix E | Foundational and Minor byte-exact vectors | Verified |
| KLV insertion cadence | ST 1204.1-34 | `MISMMSValidator` Item 94 state plus exact 30-second/one-microsecond-late tests | Verified for receiver-visible recurrence; the producer supplies sensor-change events |
| Allowed UUID versions and null-MAC rule | Appendix A / ST 1204.1-42/-44 | `validate_miis_uuid`, strict Core Identifier construction/decoding, and version 1/4/5 generators | Verified |
| Unique version-5 source information | Appendix A / ST 1204.1-43 | `generate_miis_uuid5` requires explicit namespace and non-empty unique-name input | API enforces shape; caller owns uniqueness across devices |
| Multi-UUID combination | Appendix A.1 | `combine_miis_uuids` ordered uppercase UTF-8 hex/SHA-1 algorithm | Verified byte-exact against normative Table 13 |

The decoder retains the exact binary value and rejects mismatched component
counts, disallowed UUID versions/variants, and a version-1 null MAC node. The
encoder accepts typed `UUID` components, prevents mixing Minor and Foundational
identifiers, and emits the minimum one-octet BER-OID for the currently supported
structure version.

```python
from uuid import UUID

from stanag4609 import combine_miis_uuids, generate_miis_uuid5

sensor_id = generate_miis_uuid5(
    UUID("6ba7b810-9dad-11d1-80b4-00c04fd430c8"),
    "manufacturer:model:serial",
)
payload_id = generate_miis_uuid5(
    UUID("6ba7b810-9dad-11d1-80b4-00c04fd430c8"),
    "manufacturer:model:serial:payload",
)
fused_sensor_id = combine_miis_uuids((sensor_id, payload_id))
```

Combination is deliberately not implemented with `uuid.uuid5`: Appendix A.1
omits a namespace and hashes the concatenated uppercase, dash-free hexadecimal
*characters*, not the 16-byte UUID values. Input order is therefore preserved
and significant.
