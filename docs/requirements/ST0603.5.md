# MISB ST 0603.5 requirement trace

This trace covers the official 5 October 2017 publication, *MISP Time System
and Timestamps*.

| Requirement/area | Implementation/test | State |
| --- | --- | --- |
| §6, strictly monotonically increasing MISP Time System | `verifier.FMVVerifier` embedded timestamp chronology | Repeated and unannounced reverse values rejected across microsecond/nanosecond representations; declared reverse and MPEG-TS discontinuities start or identify timing changes |
| §7.1 / ST 0603.4-08, Precision Time Stamp | ST 0601 and ST 0604 unsigned 64-bit microsecond codecs; producer validation context | Wire representation verified; sampling/truncation truth requires producer context |
| §7.2 / ST 0603.5-09, Nano Precision Time Stamp | ST 0604 unsigned 64-bit nanosecond codec | Wire representation verified; sampling/truncation truth requires producer context |
| §7.3, Nano Precision to Precision conversion | `nano_precision_to_precision_timestamp` | Exact integer `(value + 500) // 1000` mapping, all three official Table 1 vectors, half-up boundary, and UINT64 boundary verified |
| §7.3, Precision to Nano Precision conversion | `precision_to_nano_precision_timestamp` | Exact integer `value * 1000` mapping, both official Table 2 vectors, and UINT64 output-overflow rejection verified |
| §7.4, Time Status | `st0604.TimeStatus`, `decode_time_status`, `encode_time_status` | Lock, discontinuity, direction, required reserved bits, and invalid reverse-state tests verified |
| §7.5 / ST 0603.2-07, Commercial Time Stamp | — | Optional SMPTE ST 12-1 profile, not implemented |

The checksum-bound inventory contains all three active and six deprecated
numbered requirements. Requirements ST 0603.4-08 and ST 0603.5-09 describe
producer sampling of the MISP Time System; a receiver can verify their UINT64
representations but cannot infer the discarded sub-unit source time. The API
therefore does not make a false producer-truth claim.
