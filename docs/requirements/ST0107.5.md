# MISB ST 0107.5 requirement trace

This trace records the common KLV and Report-on-Change rules used by the
ST 0601 and ST 0902 implementation. The checksum-bound official publication
dated 21 October 2021 contains exactly 20 active requirements and no retired or
deprecated requirements. The official SMPTE ST 336:2017 publication is present
locally; its clause-level audit is tracked separately and is not implied by
this MISB-only trace.

`ReportOnChangeState` retains multiple instances of one tag as an atomic group.
Identity-aware merging for distributed lists and the specialized lifecycle of
Segment, Amend, and command structures require their own
stateful evaluators and are not claimed here. ST 0601's distributed wavelength
and payload tables are handled separately by `WavelengthTableState` and
`PayloadTableState`; `WeaponsStoresState` handles the distributed Item 140 list
by its four-part physical addresses, and `WaypointListState` handles Item 141
by Waypoint ID while preserving transient reorder conflicts.

ST 0107.4-14 is a producer-state obligation: absence from the wire does not
reveal whether the producer still considers an optional item Known or has let
it become Unknown. `MISMMSValidator` enforces cadence for the selected required
ST 0902 population because those items are known to be required. For arbitrary
optional reportable items, applications must supply the producer-side Known
state; the receiver independently implements ST 0107.4-15 by expiring silent
values after the configured refresh period.

`IMAPFieldValue(value, length)` remains available when an application already
owns a validated wire precision. Producers that start with a physical precision
should use `IMAPFieldValue.for_precision(tag, value, precision)` so the library
selects the shortest legal value length using ST 1201 IMAPA rather than relying
on a hand-picked byte count. Relays and receivers that know the originating
system precision can supply the same fact through `ST0601ValidationContext`;
live transports and the verifier select that context per complete packet with
`ST0601ContextProvider`;
the decoder then rejects both undersized values that lose precision and
oversized values that violate shortest-form encoding.
