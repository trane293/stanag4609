# MISB ST 0806.4 requirement trace

This trace covers the official 27 February 2014 Remote Video Terminal Metadata
Set publication. The API distinguishes an independent Universal KLV packet
from a nested Local Set value. A nested value deliberately omits the Universal
Key, outer length, and CRC as required by ST 0601.19 Section 6.3.3.
The machine-readable requirement inventory binds all 25 active identifiers and
the empty inactive population to the publication's checksum-pinned source.

Unknown extension items remain available byte-for-byte through the lossless
`LocalSet`. Encoding an unknown item requires an explicit `RawRVTValue`, which
prevents an untyped Python value from silently receiving an invented wire
representation.

The independent-packet encoder owns timestamp ordering and CRC generation.
The embedded form rejects CRC Item 1 and is used directly by ST 0601 Item 73.
`RVTValidationContext` verifies timestamp truth when the producer or test
harness supplies the metadata birth time. The real-world position represented
by a lexically valid MGRS coordinate, user-defined meanings, and POI/AOI content
remain the producer's responsibility.
