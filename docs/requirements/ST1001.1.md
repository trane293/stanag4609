# MISB ST 1001.1 requirement trace

The official five-page ST 1001.1 publication dated 27 February 2014 defines the
audio baseline. It permits MPEG-1 Layer II, MPEG-2 Layer II, and MPEG-2 AAC-LC.

| Requirement | Implementation/test | State |
|---|---|---|
| ST 1001.1-01, writers select an allowed codec | `st1001` maps PMT stream types `0x03`, `0x04`, and `0x0F`; `validate_st1001_audio_profile` rejects known non-profile audio signaling | Verified codec-selection profile |
| §7.1 MPEG-1 Layer II CRC/CBR guidance | Layer II header inspection exposes CRC, bitrate, sample rate, mode, and frame size | Inspection verified; recommendation is caller policy |
| §7.2 MPEG-2 Layer II base audio and added-channel warning | Layer II header inspection distinguishes MPEG-2 and base mono/stereo modes | Base header verified; MPEG-2 multilingual/multichannel extension not decoded |
| §7.3 MPEG-2 AAC-LC ADTS CRC guidance | ADTS inspection enforces MPEG-2 AAC-LC and exposes CRC, sample rate, channel configuration, and frame size | Header inspection verified |
| Streaming compressed-frame boundaries | `AudioFrameParser` reconstructs Layer II and AAC-LC ADTS frames across arbitrary chunks with bounded partial state | Verified for all three profile codecs |
| PES presentation timing | `AudioPESFrameParser` assigns H.222.0 PTS to the first frame commencing in a PES and derives exact following times | Split/start/continuation/rollover tests verified |
| File-level audio diagnostics | `FMVVerifier` incrementally composes `AudioPESFrameParser` per program/PID and reports frame/sample/rate/channel/timing totals, malformed headers, missing payload, and trailing truncation | Verified for all parser-supported ST 1001 codecs; real AAC transport acceptance |
| ST 1001.1-02, decoders accept every allowed codec | `audio.PyAVAudioDecoder` maps both Layer II profiles to FFmpeg `mp2` and AAC-LC to `aac` | Dedicated optional-backend CI decodes actual frames for all three formats; real AAC FMV demux-to-PCM acceptance |

The pure-Python core discovers, identifies, time-aligns, demultiplexes,
remultiplexes, and preserves every audio elementary stream. It can inspect the
base MPEG Layer II and ADTS headers without decoding compressed samples. AAC
channel configuration is explicit in ADTS; MPEG-2 Layer II multilingual and
multichannel extensions require deeper codec parsing and are intentionally not
inferred from the base header.

`AudioFrameParser` composes those header codecs into a bounded incremental
elementary-stream parser intended to be instantiated once per audio PID. It
returns each frame's exact bytes and offset plus channel count, sample rate,
sample count, and exact rational duration. Free-format Layer II is rejected
because its frame boundary cannot be inferred from the header alone.

`AudioPESFrameParser` composes that byte parser with the live demux event API.
It keeps timestamps attached to a frame that begins in one PES and finishes in
another, does not incorrectly assign a PES PTS to a continued frame, unwraps
the 33-bit clock, and derives subsequent frame times as exact rational values.

As a local acceptance check, FFmpeg stream-copied the supplied
`Raw_Video.mpeg` audio elementary stream and the parser reconstructed all 6,215
MPEG-1 Layer II frames from arbitrary 65,537-byte chunks: 48 kHz stereo,
7,159,680 compressed bytes, and exactly 149.16 seconds, matching FFprobe.

Actual compressed-audio decoding is provided by the optional
`PyAVAudioDecoder`, which uses direct FFmpeg codec contexts and returns native
PyAV audio frames. Contract tests cover backend loading, codec selection,
ordering, flush behavior, and lifecycle; when PyAV is installed, actual codec
contexts decode generated MPEG-1 Layer II, MPEG-2 Layer II, and MPEG-2 AAC-LC
frames in a dedicated CI job. The Esri Truck fixture additionally exercises
demux, PES PTS assignment, reconstruction of 6,946 AAC access units, and decode
to 7,112,704 stereo PCM samples at 48 kHz. The reference browser player still
uses its separate FFmpeg transcode path.
