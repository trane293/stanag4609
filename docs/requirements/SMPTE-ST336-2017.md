# SMPTE ST 336:2017 requirement trace

This trace covers the ST 336 provisions used by MISB Universal KLV and Local
Sets. The official 21 July 2017 publication is retained locally with its
publisher URL and SHA-256 identity in the standards manifest. Its normative
SMPTE ST 298:2009 and ITU-T X.690:2008 / ISO/IEC 8825-1:2008 dependencies are
also retained from their official publishers and checksum-catalogued.

`KLVStreamParser` enables SMPTE-key validation automatically for its normal
16-byte `06 0E 2B 34` key space. A caller intentionally using the parser as a
generic fixed-width binary framing primitive can set
`validate_smpte_keys=False`.

## Deliberate scope boundary

ST 336 also defines Universal Sets, Global Sets, Variable-Length Packs,
Defined-Length Packs, and wrapper/container categories. Those general SMPTE
constructs are not currently exposed as high-level codecs. The supported MISB
standards use the `0x0B` Local Set form, so this boundary does not weaken the
claimed ST 0601, ST 0902, or ST 0903 path. Unknown complete KLV packets remain
losslessly available for application processing as ST 336 requires.
