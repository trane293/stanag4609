# MISB ST 0903.6 requirement trace

The official 72-page ST 0903.6 publication dated 21 October 2021 is the VMTI
baseline. It explicitly covers moving and static object detections, AI/ML
processing results, pixel and geospatial bounding boxes/contours, object and
feature labels with confidence, target lifecycle, and track history.
This trace explicitly accounts for all 65 active requirement identifiers before
the standard's deprecated-requirements section. The checksum-bound requirement
inventory separately records all 78 deprecated identifiers, and CI prevents a
deprecated identifier from being presented as current evidence. Shorthand
never hides an untraced active identifier.

Implemented slices cover standalone and embedded VMTI Local Sets, VTarget
Series, core pixel/lifecycle fields, VMask contours/run masks, VChip image
references/embeds, absolute Location and Boundary Series geometry, VTracker
state, typed ST 1204 MIIS identity, and packet-scoped Algorithm, Ontology,
VObject, and VFeature metadata.
Unknown future tags remain available through the lossless Local Set model and
require an explicit raw-value wrapper when newly encoded.

removed, because each packet may intentionally report only a subset.
