## ST 0806 RVT metadata embedded by Item 73

Independent RVT packets carry their own timestamp and CRC-32. Embedded Item 73
values omit the Universal Key, outer length, and CRC. Supply
`RVTValidationContext` when producer-known metadata time of birth is available;
the codec fails rather than silently treating an absent or mismatched timestamp
as externally assured.

```python
from datetime import datetime, timezone

from stanag4609 import RVTValidationContext, decode_rvt_local_set

context = RVTValidationContext(
    metadata_birth_timestamp=datetime(2024, 1, 2, tzinfo=timezone.utc),
)
rvt = decode_rvt_local_set(independent_rvt_packet, context=context)
```
